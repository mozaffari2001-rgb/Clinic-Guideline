!قبل از هر چیز

Otoscopy لازم است. اگر عفونت، ترشح یا جرم زیاد دیدید، تست نکنید و با کلینیک هماهنگ کنید.
  • Ear tip برای هر بیمار نو یا ضدعفونی‌شده.
  • اتاق ساکت؛ بیمار آرام و بی‌حرکت (نوزاد ترجیحاً خواب).
  • این راهنما برای کامپیوتری است که Capella با NOAH 3 و برنامه‌ی OAE SYSTEM کار می‌کند. اگر با OTOsuite کار می‌کنید، راهنمای «OAE Madsen Capella · OTOsuite» را ببینید.

۱ورود به NOAH

۰ از ۵ انجام شده
  1. 1User name (اینجا ABC)
  2. 2Password: از مربی بپرسید
  3. 3Select database: NOAH Database
  4. 4OK

۲پیدا کردن یا ثبت بیمار

  1. 1تب‌ها: All Clients (همه)، Recent Clients (اخیر)، Search for Clients (جست‌وجو با Last Name و دکمه‌ی Search)
  2. 2فهرست بیماران: روی نام بیمار دو بار کلیک کنید.

بیمار جدید New Client

اگر بیمار در فهرست نیست، از منوی File گزینه‌ی New Client را بزنید.

  1. 1First name و Last name
  2. 2Gender و Date of birth
  3. 3Work with Client: ذخیره و رفتن مستقیم سراغ همین بیمار
  4. 4OK: فقط ذخیره

Session Browser

  1. 1نام و تاریخ تولد بیمار انتخاب‌شده؛ بررسی کنید بیمار درست است.
  2. 2جلسه‌های قبلی و جلسه‌ی امروز

از اینجا برنامه‌ی OAE (Capella) را از نوار ابزار NOAH باز کنید. پنجره‌ی OAE SYSTEM با نام بیمار در عنوان باز می‌شود.

۳TEOAE

  1. 1منوی Mode: نوع تست، TEOAE یا DPOAE
    منوی Ear: انتخاب گوش
  2. 2شکل موج پاسخ؛ A و B دو ثبت هم‌زمان‌اند
    (A+B)/2 = پاسخ، (A-B)/2 = نویز
  3. 3طیف فرکانسی: نارنجی = پاسخ (Resp.)، مشکی = نویز
  4. 4Statistics برای هر باند فرکانسی و کل:
    Correlation %, Emission strength, S/N ratio
  5. 5Sweeps: Accepted, Rejected, Completed %
  6. 6Meas. no.: شماره‌ی اندازه‌گیری؛ با فلش‌ها بین ثبت‌ها جابه‌جا شوید
  7. 7Fit: چراغ وضعیت probe؛ سبز = قرارگیری خوب
  8. 8Stimulus: شدت click، پیش‌فرض 80 dB؛ بدون اجازه‌ی مربی تغییر ندهید
  9. 9Start شروع و Pause مکث
  10. 10ذخیره (آیکون دیسکت)
  1. از منوی Mode تست TEOAE و از منوی Ear گوش را انتخاب کنید.
  2. Probe را بگذارید و صبر کنید چراغ Fit سبز شود. اگر نشد، probe را جابه‌جا یا ear tip را عوض کنید.
  3. Start را بزنید و تا Completed: 100% صبر کنید.
  4. Rejected زیاد یعنی نویز زیاد (بیمار یا محیط)؛ بیمار را آرام کنید و دوباره بگیرید.
  5. ذخیره کنید، گوش را عوض کنید و تکرار کنید.

۴DPOAE

  1. 1DP-gram: خط سبز = سطح DP1، خط قرمز = نویز، ناحیه‌ی هاشورخورده = محدوده‌ی نرمال
  2. 2مربع‌های زیر هر فرکانس: انتخاب فرکانس‌های تست
  3. 3طیف فرکانسی با قله‌های F1 و F2 و محل DP1 و DP2
  4. 4DP1: Level و Noise فرکانس انتخاب‌شده
  5. 5S/N-ratio و معیار توقف S/N-ratio Stop، اینجا 6 dB
  6. 6Sweeps: Accepted, Rejected, Completed
  7. 7Fit: چراغ وضعیت probe
  8. 8Frequency: فرکانسی که جزئیاتش نشان داده می‌شود؛ با فلش‌ها عوض کنید
  9. 9F1 Level، اینجا 65 dB
  10. 10Start و Pause
  1. از منوی Mode تست DPOAE را انتخاب کنید و گوش را از منوی Ear.
  2. چراغ Fit را چک کنید و Start بزنید.
  3. در هر فرکانس، پاسخ (خط سبز) باید به‌وضوح بالای نویز (خط قرمز) باشد. S/N بالای معیار توقف یعنی پاسخ معتبر.
  4. ذخیره و تکرار برای گوش دیگر.

نبود پاسخ به معنی کم‌شنوایی قطعی نیست؛ جرم، مایع گوش میانی یا seal بد هم پاسخ را کم می‌کنند. تفسیر نهایی با مربی.

۵ذخیره و پایان کار

  1. در OAE SYSTEM با آیکون دیسکت ذخیره کنید و پنجره را ببندید؛ نتیجه در جلسه‌ی امروز بیمار در NOAH ثبت می‌شود.
  2. در Session Browser چک کنید جلسه‌ی امروز ثبت شده است.
  3. Ear tip را دور بیندازید یا ضدعفونی کنید. Probe را با دستمال نرم کمی مرطوب پاک کنید؛ مایع وارد probe نشود.
  4. هر مشکل را در دفتر دستگاه بنویسید و به کلینیک (021 7753 0636) خبر دهید.

؟Troubleshooting
