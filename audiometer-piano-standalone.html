!قبل از هر چیز

وقتی frequency، transducer یا گوش را عوض می‌کنید، شدت قبلی می‌ماند و ممکن است صدای بلند و آسیب‌زا پخش شود. قبل از ارائه، intensity را پایین بیاورید.
  • برای بالاتر از 100 dB HL باید اول HIGHER dB زده شود؛ بدون اجازه‌ی مربی نزنید.
  • Insert earphone بدون foam tip ممنوع؛ foam tip یک‌بارمصرف است.
  • با transducerها با احتیاط کار کنید؛ هدفون را روی سطح صاف فشار ندهید.
  • برای تمیز کردن دستگاه و صفحه‌ی لمسی از مایع یا اسپری استفاده نکنید.

۲آشنایی با دستگاه

ورودی و خروجی هر کانال با کلیدهای INPUT و OUTPUT (بالا/پایین) عوض می‌شود و روی صفحه نمایش داده می‌شود. کلیدهای پایین صفحه لمسی‌اند.

  3. 3PULSED: تُن پالسی به‌جای continuous
  4. 4TRACKING و LOCK (برای masking)
  5. 5گوش کانال ۱: RIGHT (قرمز) / LEFT (آبی)
  6. 6کانال ۱: OUTPUT (بالا/پایین: FF، AC، BC) و INPUT (TONE، WARB، MIC، …)
  7. 7پیچ شدت کانال ۱
  8. 8NORM. ON کانال ۱
  9. 9INTERRUPTER کانال ۱: ارائه‌ی محرک
  10. 10کانال ۲: INPUT و OUTPUT (masking)؛ پیچ و RIGHT/LEFT و INTERRUPTER کانال ۲ سمت راست پنل‌اند
  11. 11STORE
  12. 12کلیدهای FREQUENCY؛ در گفتار همین‌ها INCORRECT / CORRECT هستند
  13. 13TALK OVER: صحبت با بیمار

۳آماده‌سازی بیمار

  1. Case history و otoscopy (جرم، collapsing canal).
  2. برای بیمار جدید: NEW PATIENT. همه‌ی تست‌های جلسه‌ی فعلی پاک می‌شود؛ اگر قبلی را منتقل یا چاپ نکرده‌اید، اول آن را انجام دهید.
  3. توضیح به بیمار: «هر بار صدای بوق شنیدید، حتی خیلی ضعیف، دکمه را فشار دهید.»
  4. عینک، گوشواره و سمعک را بردارید. هدفون: قرمز = راست، آبی = چپ.

۴Pure Tone · Air Conduction

  1. صفحه‌ی Pure tone (اگر در گفتار هستید، PTA پایین صفحه).
  2. کانال ۱: INPUT روی TONE (یا WARB)، OUTPUT روی AC (نوع هدفون یا insert با AC TRANSDUCER پایین صفحه)، گوش با RIGHT یا LEFT. برای بیمار وزوزی PULSED را بزنید (روی صفحه Mode عوض می‌شود).
  3. فرکانس با کلیدهای FREQUENCY، شدت با پیچ چپ. ارائه با INTERRUPTER (۱ تا ۲ ثانیه).
  4. روش modified Hughson-Westlake: پاسخ داد ← ۱۰ پایین؛ پاسخ نداد ← ۵ بالا. Threshold = کمترین شدتی که در ۲ از ۳ بار صعودی پاسخ دهد.
  5. STORE تا نماد روی audiogram بیاید. برای اصلاح، در شدت درست دوباره STORE. بدون پاسخ در حداکثر: وقتی محرک را در حداکثر شدت ارائه کنید، کلید لمسی NO RESPONSE روی صفحه ظاهر می‌شود؛ آن را بزنید.
  6. ترتیب رایج: 1k → 2k → 4k → 8k → 1k (retest) → 500 → 250 Hz؛ اختلاف ≥ 20 dB بین دو اکتاو ← inter-octave.
Auto Threshold (فقط با اجازه‌ی مربی)
  • روش خودکار Hughson-Westlake. Frequencyها با FREQ. SELECTION، شروع با START EXAM.
  • آستانه‌های AC ذخیره‌شده‌ی قبلی پاک می‌شوند. اول در 1 kHz و 40 dB HL آشناسازی دارد و بین دو گوش جابه‌جا می‌شود.

۵Bone Conduction

  1. Bone vibrator روی mastoid، بدون تماس با لاله‌ی گوش و بدون مو زیرش.
  2. روی صفحه transducer کانال ۱ را BC کنید.
  3. معمولاً 250 تا 4000 Hz با همان روش؛ STORE.
  4. در 250 و 500 Hz با شدت بالا بپرسید «شنیدید یا لرزش حس کردید؟» (vibrotactile).

۶Masking

40 dB
IA حداقلی supra-aural
0 dB
IA برای BC
ACاختلاف AC گوش تست با BC گوش مقابل ≥ IA (هدفون ۴۰، insert حدود ۵۵ به بالا)
BCAir-bone gap گوش تست بیشتر از 10 dB
  1. کانال ۲: با INPUT ورودی را روی NBN بگذارید (پیش‌فرض صفحه WN است). OUTPUT = AC یا INS. گوش نویز باید مقابل گوش تست باشد؛ روی صفحه SIDE را چک کنید.
  2. سطح با knobی راست؛ طبق روش plateau پیش بروید.
  3. LOCK: نویز همراه تُن. NORM.ON: نویز دائم روشن تا interrupter زده شود. TRACKING: اختلاف ثابت بین تُن و نویز.
  4. در BC masking هدفون فقط روی گوش مقابل؛ گوش تست باز.

سطح اولیه و plateau را طبق روش کلاس حساب کنید؛ مراقب over-masking باشید.

۷Speech Audiometry

  1. 1تست فعال (TEST: WRS)
  2. 2VU-meter: صدای میکروفن حدود 0
  3. 3جدول SRT، WRS، MCL، UCL؛ فلش = تست فعلی
  4. 4شمارنده‌ی WRS (درست / کل و درصد)
  5. 5کانال ۱: INPUT MIC (یا EXT2، INT1)
  6. 6کانال ۲: SN (speech noise) برای masking گفتار
  7. 7RESET SCORE
  8. 8PTA: بازگشت به pure tone
  1. کلید لمسی SPEECH پایین صفحه. تست (SRT، WRS، …) را انتخاب کنید و گوش و OUTPUT را تنظیم کنید. برای masking گفتار، کانال ۲ روی SN.
  2. Input: INT1/INT2 (فایل گفتاری روی دستگاه)، EXT1/EXT2 (منبع بیرونی) یا MIC (live voice؛ میکروفن نزدیک دهان، VU meter حدود صفر).
  3. برای WRS: پاسخ درست ← CORRECT؛ نادرست ← INCORRECT (بسته به حالت شمارش). صفر کردن شمارنده: RESET SCORE.
  4. STORE برای ذخیره‌ی نتیجه.

۸چاپ، انتقال و پایان کار

  1. چاپ: PRINT (اگر printer داخلی دارد).
  2. انتقال به کامپیوتر (اگر لازم شد): TO PC با Maestro باز روی کامپیوتر.
  3. قبل از بیمار بعدی حتماً نتیجه را چاپ یا منتقل کنید؛ NEW PATIENT همه را پاک می‌کند.
  4. Cushionها و bone vibrator را بعد از هر بیمار با دستمال الکلی تمیز کنید. Foam tip را دور بیندازید.
  5. هر مشکل را در دفتر دستگاه بنویسید و به کلینیک (021 7753 0636) خبر دهید.

؟Troubleshooting

از transducer صدا نمی‌آیدانتخاب transducer و گوش روی صفحه و اتصال پشت دستگاه را چک کنید؛ اگر درست بود، خبر دهید.
دکمه‌ی بیمار کار نمی‌کنداتصال patient response switch.
صدای بیمار شنیده نمی‌شوداتصال میکروفن بیمار و ولوم talk back.
INT1/INT2 انتخاب نمی‌شودفایل گفتاری روی دستگاه نیست؛ از MIC یا EXT استفاده کنید.
صفحه‌ی لمسی دقیق کار نمی‌کندصفحه resistive است؛ محکم‌تر با نوک انگشت بزنید. با شیء تیز نزنید.
